# AI Utilization Statement

This note describes AI use that is visible in the AJS project workflow handled in this Codex workspace. It is not a claim that every line of code was generated by AI, nor a complete audit of every contributor's local tools.

## GPT

GPT was used in conversation to clarify requirements, review implementation risks, and help prioritize work for the assessment. Topics included the procurement workflow, Admin/Buyer access, product image handling, inventory behavior, and the company landing-page content. The project owner supplied business context and constraints. In particular, the decision to reduce stock when an Admin confirms an order was provided by the project owner.

## Codex

Codex inspected the repository before making scoped changes, implemented selected backend and frontend changes requested during the project, and ran the relevant Go tests/build and frontend lint/build commands when requested. Codex also checked routes, API response shapes, seed data, environment variable names, and current UI behavior while preparing this documentation.

AI assistance was applied to specific tasks; the repository was not treated as wholly AI-generated. The project owner remains responsible for reviewing the code, validating business claims and demo data, protecting credentials, and deciding what is submitted.

## Limits and review
